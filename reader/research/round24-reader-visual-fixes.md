# 第 22–24 轮：实际渲染、插图和离线阅读版

日期：2026-09-22。实施与视觉检查：主代理；独立阅读版审查另见第 23 轮报告。

## 实际发现的问题

1. 第 08、16、18 章共三处 Mermaid 图在真实渲染器中报错。函数括号、量子态符号或边标签未适当加引号。已修正源文件并实际生成全部 20 张流程图。
2. 第 12、16、17 章部分图把 `\n` 显示为字面字符，而不是换行。已使用支持的标签换行；这说明“代码围栏完整”不等于“图能正常显示”。
3. 原总览图横向过长，缩小后难读。改为分组纵向学习图，保留原有精确先修表。变分算法流程改为纵向排列。
4. Bloch 球顶部箭头靠近副标题，正 X 标签被参数说明框遮挡；低温控制图的说明框挡住箭头末端；硬件控制图的反馈虚线穿过平台标签。均调整几何位置，并重新查看截图。
5. Markdown 数学中的态矢量竖线可能破坏表格解析。构建时先保护数学片段，再解析正文并恢复已渲染公式。
6. 窄屏中 KaTeX 隐藏层曾引起整页水平溢出。限定公式容器定位与滚动范围后逐页复测。目录中的数学标题同步使用已渲染标题，避免显示裸美元符号。

## 新增内容

- 新增 Bell 态制备电路 SVG：标出 A/B 基序、H 门、CNOT 控制与目标、三个阶段的联合态，支持明暗配色。第 04 章加入逐步读图说明；硬件审稿者独立核验线路与图注。
- 新增离线阅读版：27 个页面，含正文、附录与编辑规范；章节搜索、章内目录和前后章导航；字体、公式、图片、审校报告和许可证随目录保存，不依赖外部网络。
- 原始论文与官方资料仍由各章就近引用，阅读版不会把排版库文档当作科学结论的依据。

## 验证方式与边界

构建报告记录公式与图的渲染结果。浏览器验证覆盖 1440 与 390 像素两种宽度下的全部 27 页，检查公式数量、占位符、样式加载、图片、表格、本地链接、锚点、目录搜索与页面级溢出。人工查看选定页面截图，以及六张科学 SVG；Bell 图额外查看深色版本。SVG 文字边界检查包含坐标变换，但不会自动证明标签之间没有遮挡，因此仍保留人工看图。

最终数量与通过状态以最新 `reader-build-report.json`、`reader-verification.json` 为准。网页打印样式已提供，但没有把打印版作为逐页验证过的 PDF 发布。

## 第 23 轮交叉审查后的回归补强

针对三个验证覆盖问题，构建报告已加入源 Markdown、生成 HTML、构建器、样式和源 SVG 的 SHA-256；验证时发现构建后输入变化会失败。公式按原始 TeX 顺序计算摘要，再与浏览器中的 MathML TeX 注释比较；标题 ID 也逐项核对，不再只看总数。

所有存在水平滚动的公式、表格和流程图均程序化滚到最右端并验证可达。另增加手机目录展开截图、表格/公式/流程图末端截图及第 04 章整页截图。第 04 章整页用于检查下半部协议、算式与导航，而非声称全部长页均逐像素人工验收。打印与导出 PDF 仍为明确的非交付范围：浏览器打印入口是辅助功能，正式阅读与验收对象是离线 HTML。
