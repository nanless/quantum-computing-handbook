# 独立复核程序

第71轮交换审稿的核算也放在codes，便于离线运行。原始执行脚本和报告保留在work/research，不覆盖历史证据。

- `python3 codes/review/cross_foundations.py`：复数Schmidt谱投影、Bell-bra传态、矩阵单位上的噪声、联合密度擦除、纯/混态协方差界。
- `python3 codes/review/cross_systems.py`：Steane支持枚举、四比特物理交换电路、任意赤道轴相位帧、精确小模型序贯概率和谱积分。

两程序只复用本书其他组的基础矩阵/数值助手，不导入被审组对应的实现；独立性指计算路径与对象构造，并非每一行算术原语都另写一份。全部输入是明示的理想模型或合成数据，不是真机样本，不是完整定理证明。程序拒绝-O，第二个入口将本轮结果写入当前布局的work/research。详情见教材审校记录及第71轮跨组报告。
