# 第 72 轮系统组：八章独立复算

普通 Python 3.9+ 标准库即可执行：

```sh
python3 codes/systems/round72_checks.py --case all
```

单章 `--case` 支持 `09,10,11,12,14,15,19,q3`。禁止使用 `-O`。固定输入取自已实际运行的 SDK 归档，输出保留为 `round72-results.json`；单章输出另取对应名称，不覆盖历史轮次。

| 章级入口 | 独立复算对象 | 与 SDK 的区别 |
|---|---|---|
| 09 | Pauli 错误概率与平均门重叠、两级换算 | 显式算术，未调用 Stim |
| 10 | 每条归档实际/预测逻辑 bit 重计失败，核查哈希 | 标准库解析 ZIP/NPY 字节，未重新采样或译码 |
| 11 | 精确二项尾反演及零失败上界 | 递推二项概率、二分反演，未调用 SciPy Beta 分位数 |
| 12 | 1000 发射、624 到达与确认时间，C KEM 运行记录 | 核查保存的全部事件与字节/功能计数，不替代 SDK 运行 |
| 14 | 从 CSV 用 Pauli 矩阵指数闭式传播 80 槽 | 不调用 qutip-qtrl、QuTiP 或 SciPy |
| 15 | 四份原样本哈希与重建波形交叉 | 区分归档一致性与跨机器同种子身份 |
| 19 | 20 项反馈队列的排队与截止时间 | 用 Fraction 有理数，避免浮点交界误判 |
| Q3 | 完整三维矩阵 Taylor 指数、归一化与泄漏 | 49 项级数传播，独立于 SciPy expm |

这八项复算已经全部通过。结果、模型解释、练习与答案分别嵌入各章 S72 小节，没有改变原自检编号。

完整发布包的安装、实际 SDK 算法/优化、C 构建、精确参数与全部结果见 [SDK README](sdk/README.md)。`sdk/systems_calculations.py` 是 NumPy/SciPy 的 Fréchet 梯度核查，**不是标准库入口**；不要混淆二者。

本目录的 `.npz` 是真实本地模拟器生成的合成样本，不是硬件原数据。可重建全部逻辑失败计数；特定运行的 13/2/0 不应当成所有平台、软件版本与种子的强制期望。预览图 SVG 由归档数据生成，零失败点使用上界标记，不将零点虚构为某个正数。
