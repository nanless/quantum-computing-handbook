实验、练习、代码与声音

这里把全书 24 篇正文连接到可运行的小实验。先读题目、写预测，再运行程序；每题都有计算过程、答案和模型边界。既有的 251 道自检及答案保持原编号，新增实验使用独立标签。

怎样开始

  1. 零基础从基础实验册的 F00、F01、F02 开始。
  2. 算法读者先做QPE 与 Grover，再比较变分、QSVT 和容量。
  3. 工程读者使用系统实验册，逐层连接标签、译码、资源、网络、映射与服务可用率。
  4. 用统计实验检查结论是否受 shots、外推和多重比较影响。
  5. 用声音实验听相位和对比度的教学映射，并回到公式核对。声音是程序合成，不是真实设备录音。

运行方式与结果

本轮自编数值实验使用 Python 3.9 及以上的标准库；不用账户、不调用云服务。不要加 -O 关闭断言。绘图程序另需指定版本的 matplotlib 和 NumPy；不重画图就无需安装它们。

python3 codes/run_all.py

在仓库根目录运行上面的统一入口；分章运行见代码说明。检查项覆盖概率/态归一化、独立解析式、四个测量分支、资源边界、位序、离散化收敛、源码哈希与音频格式。数值通过意味着本模型在检查点一致，不是对全部物理公设、定理和工业优势的证明。

如何把练习改成自己的研究

一次只改变一个因素：先把初态换成含非零复相位的态，再改变噪声，再增加系统大小。记录何时解析断言仍成立、何时已越出模型条件。失败例子比只贴一张漂亮成功图更有价值。

真实硬件实验还需要软件锁定、编译与校准快照、原始计数、时间顺序和费用预算。第三方源码清单支持代码溯源，没有替读者完成这些设备实验。
