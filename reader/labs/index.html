实验、练习、代码与声音

本手册把全书 26 篇正文（主篇第 00–21 章与量子力学基础篇 Q1–Q4）连接到本地可运行的动手实验与浏览器互动沙盒。学习每个主题时，建议先读题目、在草稿纸上写出预测，再运行程序核对每一步推导、答案与模型边界。全书 26 篇正文的 271 道自检题及分级零跳步参考解答（含难度标签、防剧透核心提示与四步完整演算）均已收录于附录 D；离线统一检验入口现包含 38 项纯 Python 3 标准库实验与校验脚本。

怎样开始

  1. 零安装视觉直觉上手（推荐首站）：直接在浏览器打开离线交互量子实验台（6 模块沙箱）——无需配置任何 Python 环境，即可交互体验 01 MZI 干涉与实时声化、02 Bloch 球真弧沙盒、03 Ramsey 退相干对比、04 Bell 偏迹与 CHSH 博弈、05 Grover 半拍放大与过冲陷阱以及 06 d=3 表面码注错解码六大核心模型。
  2. 零基础入门主线：打开基础实验册，从 F00、F01、F02 起步亲手核对抽样波动、左共轭内积与 Y 基测量门序，再跟进十一组诊断反例与开放动力学轨迹对照。
  3. 算法与经典模拟路线：使用算法实验册，先完成 QPE 与 Grover（06-A、07-A），再贯通高阶算法与 QSVT 专题核验（LCHS、Carleman、6 门 PREPARE–SELECT、QROM 与 4×4 负谱 QSVT），以及第 21 章稳定子表、MPS / 二维 PEPS 与含噪 Pauli 传播三引擎探究（21-A）。
  4. 硬件、纠错、系统与传感路线：使用系统与传感实验册，逐层贯通读出告警、加权解码、魔法态调度、量子网络、编译映射、服务可用率与系统条件边界，并完成第 20 章量子传感、Huelga 退相位、原子钟与重力仪分步实验（S20）。
  5. 统计方法与编译等价性路线：用统计与实验方法实验册核查有限样本下界、ZNE 固定总 shots 最优分配、BCa / Cluster Bootstrap、零失败反例、少聚类 tB−1​ 区间、多重比较与 QCEC 随机态探针。
  6. 听觉直觉与完整开源 SDK 实跑：用声音实验册试听 5 段程序合成教学 WAV 波形（非真机录音）；读完核心章节后，按完整 SDK 实验册的 11 组端到端工作流（SDK-01 至 SDK-11），对照 31 个开源项目在隔离环境中的真实输出、上游陷阱与验收边界。

跨章软件工作流、交互实验台与声音实验

  • 端到端开源 SDK 工作流（SDK-01 至 SDK-11）：见完整 SDK 实验册，汇总 31 个开源项目（对应 122 份固定提交源码） 的真实版本、运行日志、复现的上游陷阱与独立反例。

运行方式与结果

本册全部自编教学与核验程序均仅依赖 Python 3.9 及以上标准库，默认不请求云服务、不消耗付费额度。运行测试时不要加 -O（否则会关闭断言）。绘图程序另需指定版本的 Matplotlib 与 NumPy；不重画图就无需安装它们。

在仓库根目录运行统一入口，即可一键执行全部 38 项标准库验证脚本（已内置 v4_algorithms_lab.py、v4_practice_lab.py、sensing_lab.py 与 simulation_engines_lab.py，无需跑完再重复手跑），并同步校验 122 份第三方源码 SHA-256 与 5 段合成音频格式：

python3 codes/run_all.py

若只想单独复算某一专题（如高阶算法、统计重采样、量子传感或经典模拟三引擎），也可直接单独执行对应脚本：

python3 codes/algorithms/v4_algorithms_lab.py all
python3 codes/practice/v4_practice_lab.py
python3 codes/systems/sensing_lab.py
python3 codes/algorithms/simulation_engines_lab.py

分章运行方式、预期输出与依赖清单见代码总说明。程序通过断言说明数值实现与明示模型自洽；小规模算例不能替代一般定理证明或真实硬件实验。完整开源 SDK 须在各自隔离虚拟环境中按锁定版本运行，不与默认标准库入口混跑。

如何把练习改成自己的研究

一次只改变一个因素：先把初态换成含非零复相位的态，再引入噪声或读出偏差，最后逐步扩大系统规模。记录解析断言在何处继续成立、在何处开始越出模型前提——一个精准定位失效边界的反例，往往比只贴一张漂亮的成功曲线更有研究价值。

迈向真实硬件实验时，还须同步保存软件依赖锁、编译布局与硬件校准快照、完整原始计数、采集时序与端到端机时预算。
