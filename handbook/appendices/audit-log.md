## 2. 当前版本验证边界与明确非目标

### 2.1 本版已执行的可复现验证范围

- **正文、题答与公式一致性**：全部 26 篇正文（主篇 `00`–`21` 与物理篇 `Q1`–`Q4`）的 271 道章末自检题通过稳定身份与[练习解答](exercises.md)逐题配对。构建会拒绝重复、遗漏以及已登记解答的调换；全部 Markdown 源文件统一采用 `$...$` / `$$...$$` 与 `\mathrm{...}`，通过术语统一与公式定界符自动门禁。
- **离线标准库数值验算**：仓库根目录统一入口 `python3 codes/run_all.py` 仅依赖 Python 3.9+ 标准库（不联网、不调用云端 QPU），覆盖全部章节手算算例、反例边界、统计区间、模拟引擎及 122 份第三方源码 SHA-256 完整性校验。
- **第三方源码与本地 SDK 实验**：仓库登记 31 个开源项目的固定来源。对实际运行过的项目，[完整 SDK 实验册](../labs/sdk-validation.md)给出固定版本、本地任务、样本口径与复算范围。
- **全介质构建与界面检查**：离线 Web 阅读版通过宽屏（1440px）与手机窄屏（390px）自动布局、断链、断锚、无外网请求及 SVG 边界检查；同步发布 A4 合订本 PDF、原生 MathML 3 EPUB 3 与浏览器离线交互实验台，并辅以代表性页面与新增插图的人工截图抽查。

### 2.2 质量分级门槛与明确非目标

本书修订始终遵循四级问题门槛：**P0**（数学归一化、维度、基序、复杂度类别或客观事实错误，必须立即修复）、**P1**（易引发错误物理模型的类比、缺失前提条件或术语冲突，必须修复）、**P2**（推导跳步、缺量化算例或图文衔接偏弱，按轮次优先清零）、**P3**（扩展阅读与表达润色，按教学价值纳入）。

同时，本书明确声明以下**非目标**：

1. **不宣称穷尽学科**：量子计算与量子信息没有有限终点；本书提供从零基础直觉到研究入口的扎实骨架，不替代量子复杂性、量子信息论、凝聚态物理或器件物理的专题专著。
2. **不维护厂商排行榜**：硬件指标随校准批次与新芯片快速演进，应以正文建立的指标口径与证据分级框架按一手来源实时核验。
3. **不把本地模拟等同于真机或商业优势**：小规模标准库程序与本地 CPU 开源包实跑仅检验明示数学模型与软件接口，不能替代一般定理证明、真实硬件实测或端到端商业优势论证。
4. **不将抽查冒充逐屏逐像素保证**：全介质自动化扫描覆盖所有生成页面，人工视觉检查属于针对关键页面与新增科学图的重点抽查，无法覆盖全部第三方浏览器、系统字体与自定义缩放组合。

## 3. 公开数学、事实与上游 SDK 勘误总表（Errata Log）

下表集中登记本书在正文核查、时效事实追踪与固定版本开源 SDK 实跑中发现并核验的重要勘误与边界记录，供读者复现实验或查阅文献时防踩坑：

| 类别与位置 | 发现的问题或上游变动 | 修正口径与核验状态 |
|---|---|---|
| **阅读版题答与发行物** | 旧的题数检查无法发现两题解答被调换。仅使用包内链接检查也无法发现 EPUB 的规范错误和被降为文字的实验入口。 | 正文与答案配对现在使用稳定身份。EPUB 合规检查独立运行，书内实验链接定位到配套目录。发行清单记录构建来源和文件摘要，离线包在解压后验证。 |
| **数学勘误｜第 00、01 章复位与偏迹** | 只观察 H 后的两端各半无法判断复位。相同的局部边缘可以来自不同的联合态。 | F00 加入直接 Z 读出。F01 用 Bell 态与均匀混合态核对相同边缘，对照联合态非对角元素。参见[基础实验册](../labs/foundations.md)。 |
| **数学勘误｜第 03 章 Bell 联合测量** | 局部设备分别测量 X、Z 的限制被套用于两个联合算符。 | XX 与 ZZ 共享 Bell 本征基。[第 03 章](../03-multiple-qubits.md)及第 3、4 题分别讲联合测量、局域测量和仅凭局部数据能够推断的量。 |
| **数学勘误｜第 02 章不对称读出反演方差传播** | 对 $r(m,\alpha,\beta) = \frac{m+\alpha-\beta}{1-\alpha-\beta}$（$d = 1-\alpha-\beta$），早期隔离 SDK 归档脚本（[基础 SDK 核验脚本第 66 行](../../codes/foundations/sdk73/validate_sdks.py)）曾将 $\partial r/\partial\alpha$ 与 $\partial r/\partial\beta$ 写反，得出偏大的 $Z$ 轴总方差 `0.0002956305`（标准误 `0.01719391`）。 | 正确偏导为 $\frac{\partial r}{\partial\alpha} = \frac{1+r}{d}$、$\frac{\partial r}{\partial\beta} = \frac{r-1}{d}$（满足 $r=+1 \Rightarrow \partial r/\partial\beta=0$ 物理边界）。[第 02 章](../02-single-qubit.md#83-不对称读出校准方差传播与-spam-边界)与标准库脚本已修正并经中心差分独立复算，正确 $Z$ 轴总方差 `0.0002749724`（标定项 `0.0000407202`，占 `14.8%`）、标准误 `0.01658229`；历史落盘 JSON 保持原貌不篡改。 |
| **数学勘误｜第 08 / 15 章线性 ZNE 固定总 shots 倍率** | 早期章节在对比两档（$\lambda=1,3$）线性外推与单档未缓解基线时，部分文字描述曾漏区分“固定每档相同 shots”与“固定总 shots 预算”下的最坏方差倍率。 | 已在正文与[统计实验 P15-B](../labs/practice.md#p15-b为什么外推到-110-不代表测出了超物理态)统一明确：固定总 shots $N$ 时，3:1 最优分配最坏方差上界为 $4/N$（单组基线的 $4\times$），等分 shots 为 $5/N$（$5\times$）；若改按每档各采 $N$ 次（总预算 $2N$），方差上界为 $2.5/N$。 |
