# 编辑与审校规范（V4）

本规范约束《量子计算：从直觉到研究入口》五篇 26 章（主篇 `00`–`21` 与量子力学基础篇 `Q1`–`Q4`）、7 份附录、7 份实验册、离线交互实验台与全部图表的写作、数学推导、事实验证及全介质出版交付。

## 1. 文风、结构与术语统一

全书追求**朴实、平和、有温度、写给真正初学者**的讲解方式——像一位懂行又耐心的老师拿着草稿纸坐在读者身边一步步演算。

1. **五步自然展开**：引入重要概念时，依次做到：先抛出一个具体困惑 → 给出贴近直觉或物理画面的比方（并自然指出比方在哪一步失效） → 给出干净严谨的数学定义 → 用二维或四维具体数字零跳步手算一遍 → 用图表定格关系并点出 1–2 个高频误区。
2. **一段只做一件事**：长短句错落，标题、段落、列表、公式块与图表前后留空行，保持清爽的阅读节奏。复杂主题章末或核心工具附录可配**一页速记卡**（高频公式、单位边界与选型决策树），供考前与研究速查。
3. **零跳步推导**：不使用“显然”“不难看出”“代入即得”跳过关键步骤。矩阵乘向量按行展开，内积写明左共轭，张量积写明分块顺序，复数模平方写出实部与虚部平方和；算完后尽量用归一化、概率和为 1 或迹为 1 做独立回验。
4. **V4 分级题答、两级折叠与独立标签练习规范**：
   - 附录[练习答案与推导提示](appendices/exercises.md)中的全部 271 道章末自检题答案统一采用**“难度标签 + 核心提示 + 四步零跳步全解”**结构：
     - 每题标题前置轻量难度标签：**`【基础】`**（概念直觉与单步验算）、**`【计算】`**（零跳步代数/数值手算）或 **`【进阶】`**（定理推导、反例构造或跨章综合）；
     - ① **题意与约定**（题意拆解、维度、基序、单位与待求量）之后、② **完整分步演算**之前，必须插入 1–2 行防剧透 **`- **核心提示**：...`**，仅给出破题切入点或关键恒等式，不提前泄露最终数值，供 Web 阅读版自动生成**两级渐进折叠**（先展提示 → 再展全解）；
     - 随后按 ② **完整分步演算**（关键推导配独立 `$$...$$` 公式块）→ ③ **结论与边界回验**（归一化、迹、半正定或极限自洽）→ ④ **易错坑提醒**（高频误区与口径防踩坑）收束。
   - 严禁改变各章原有 `## 自检题` 编号与附录 D 中 `## 第 N 章` / `## 量子力学 QN` 标题文本；章内与附录新增的就地/盲区进阶练习统一使用独立语义标签（如 `练 00-A`、`练 13-C`、`练 Q4-B`），避免与 271 道主自检题号冲突。答案内部的分步骤编号必须缩进或改用无序列表，避免行首顶格 `1. ` 干扰编号自动检查。

## 2. 数学公式与跨章符号契约

- **公式定界符硬约定**：全书所有 Markdown 源文件（正文、附录、实验册）**100% 统一使用 `$...$`（行内）与 `$$...$$`（块级）**，严禁残留 `\(...\)` 或 `\[...\]`；下标正体统一使用 `\mathrm{...}`，全书清零旧式 `\rm` 写法（含全局相位 $\theta_{\mathrm{g}}$）。
- **对象先行**：写公式前先交代变量的维数、取值集合与物理单位；允许不同主题复用常用字母（如 $H$、$\Omega$、$\alpha$、$\chi$、$\gamma$），但每节首次出现须界定局部含义（对照[符号表](appendices/notation.md)）。
- **内积、基序与次序**：内积采用左共轭 $\langle u\vert v\rangle=\sum_j u_j^* v_j$；多比特采用高位在左的大端序（$\lvert 00\rangle,\lvert 01\rangle,\lvert 10\rangle,\lvert 11\rangle$），遇到 Qiskit 等小端序软件显示时就地注明；电路从左向右读，算符乘积 $VU\lvert\psi\rangle$ 与信道复合 $\mathcal B\circ\mathcal A$ 从右向左作用。
- **对数底数严禁裸写**：信息论、熵、容量与比特数一律写 $\log_2$，自然对数一律写 $\ln$，不使用不标底数的裸对数。
- **保真度口径**：态保真度统一为根保真度 $F(\rho,\sigma)=\operatorname{Tr}\sqrt{\sqrt\rho\sigma\sqrt\rho}$；测量重叠概率或平方保真度明写 $F^2$ 或 $f=\langle\psi\vert\rho\vert\psi\rangle$；平均门保真度记作 $F_{\mathrm{avg}}$，平均门错误率 $r=1-F_{\mathrm{avg}}$。
- **测量与信道**：Kraus 算符统一用 $K_k$，POVM 元素统一用 $E_m$；测量必须区分结果概率、条件后态与非选择后态，不把 POVM 等同于测后演化。量子信道统一记作 $\mathcal E,\mathcal F$（$\mathcal N(\rho)$ 专用于二分态负性），并检查完全正（CP）与保迹（TP）；退极化、退相位、振幅阻尼与广义振幅阻尼（平衡激发占据 $p_{\mathrm{eq}}$）首次出现时写出完整映射与参数换算。
- **动力学、脉冲与连续变量**：Q3 与第 14 章统一采用计算基 $Z=\lvert 0\rangle\langle 0\rvert-\lvert 1\rangle\langle 1\rvert$ 与失谐 $\Delta=\omega_d-\omega_0$，并附能量基 $Z_E=-Z,\;\delta_E=\omega_0-\omega_d$ 的等价换算；DRAG 正交系数写 $\beta/\alpha$。连续变量在 Q4 用 $[\hat x,\hat p]=i\hbar$，在第 18 章无量纲正交分量用 $[\hat q,\hat p]=i$（真空协方差 $V=I/2$，多模交错序 $(q_1,p_1,\ldots,q_m,p_m)$，方形 GKP 晶胞面积 $4\pi$）。
- **精密测量与经典模拟边界**：第 20 章区分经典 Fisher 信息 $F_C(\theta)$、量子 Fisher 信息 $F_Q(\rho_\theta)$、对称对数导数 $L_\theta$、Bures 距离 $d_B$ 与 Wineland 自旋压缩参数 $\xi_R^2$，明确标注灵敏度单位（如 $\mathrm{T/\sqrt{Hz}}$）、积分时间与非纠缠基线；第 21 章统一用二元辛向量 $(x\mid z)$ 与相位位 $r$ 描写稳定子表，MPS 最大键维写 $\chi$，Pauli 串权重写 $w(P)$，稳定子秩写 $\chi_{\mathrm{stab}}$，稳定子展度写 $\xi(\lvert\psi\rangle)$。
- **混淆矩阵与 QUBO**：读出混淆矩阵统一按列随机定义 $q=Ap$（列为真实态、行为报告结果）；QUBO 与 Ising 映射须写清 Pauli $z_i=1-2x_i$ 与退火库常见自旋 $s_i=2x_i-1=-z_i$ 的符号差异。
- **复杂度与统计**：渐近加速与实际墙钟时间分开讨论，查询复杂度与门复杂度不得混用；有限样本结论须给出原始计数、样本量、统计区间（边界比例用 Wilson / Clopper–Pearson，非线性量用 Bootstrap / BCa，随机化批采样用聚类标准误）或错误率边界，点估计越过阈值不等于统计上越过阈值。

## 3. 图表与可视化

- 科学图尽量由公式或可复算数据通过脚本生成，并保存绘图代码；轴标、单位、图例与正文公式完全一致，禁止将文字转轮廓路径逃避边界检查。
- 图题与替代文字直接说明要观察的物理或算法关系，不使用“示意图 1”“流程关系图 1”这类空洞标题；非等比例示意图应显式标注。
- 全部新建科学 SVG 统一提供亮暗双主题适配（`@media (prefers-color-scheme: dark)`），颜色只做辅助编码，同时借助线型、形状或直接文字标注保证黑白打印与色觉友好；电路图统一从左向右表示时间。
- 硬件路线对比不打单一“总分”，因为相干时间、门保真度、门时长、连接性与可扩展性之间存在固有权衡。

## 4. 事实、来源与证据层级

- 数学定理与经典算法优先引用原始论文与权威教材；硬件里程碑与标准规范优先引用同行评审论文、正式标准文本及公开校准数据。
- 清晰区分证据层级：**同行评审论文 / 正式标准（A）**、**公开课程与技术报告（B）**、**预印本与厂商公告（C）**、**科技新闻与二手综述（D）**。预印本可用于追踪最新进展，但必须标明预印本身份；厂商路线图代表公开工程规划，不等于已经交付的性能。
- 会随时间变化的指标必须同时给出日期、定义口径与前提条件（例如错误率是单比特门、双比特门、读出还是每轮逻辑存储错误率，以及是否存在已知的勘误或错误底板）。
