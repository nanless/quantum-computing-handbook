# 量子力学基础篇｜从实验到量子计算

这四章补充量子计算背后的物理。目标不是要求你先学完一整套大学物理，而是让状态、测量、能量、时间演化和真实器件之间的关系清楚起来。已经学过量子力学的读者可做自检后跳过；只关心算法的读者不必先完成 Q4。

先修知识按想解决的问题来准备即可：理解门和线路，需要基本概率、复数、二维向量与矩阵乘法；理解多比特，还要会按固定基顺序展开张量积；亲手推导势阱、谐振子与隧穿，则需导数、定积分和简单二阶微分方程。主篇 [01 数学](../01-math.md)给出前两组工具。没有学过微积分时，仍可先读 Q1 和 Q2–Q3 的实验说明、物理含义与算例；Q2 的时间求导、Q3 的旋转坐标系推导可在补过导数后回看，Q4 整章可留到进阶阶段。完整大学量子力学课程通常另有波动与微分方程先修，例如 [MIT 8.04 的课程要求](https://ocw.mit.edu/courses/8-04-quantum-physics-i-spring-2013/pages/syllabus/)；那是系统学习波动力学的要求，不能直接当作阅读量子线路各章的统一门槛。

## 每章怎样学

先确定实验做了什么、记录的结果是什么，再写状态和算符。计算时沿着“振幅 → 模平方 → 概率”的顺序走，不省略归一化。碰到模型简化时，另问一句：哪些自由度或相互作用被忽略了？

读 Q2 时，尤其注意区分“基本假设”和“由假设推出的结果”。Born 规则和薛定谔演化是理论框架的一部分；已知这些规则以后，可以证明酉演化保持归一化，可以从 Hamiltonian 算出旋转门，但不能把这些计算说成从纯数学证明了整套物理定律。

## 本篇最重要的几处区分

- 一次测量的结果与许多次相同制备得到的平均值不同。
- 不知道系统处于哪个状态，与系统处于相干叠加态不同。
- 量子态的不确定度不是仪器故障，也不只等于测量扰动。
- 能量本征态只积累共同相位；不同能量成分积累不同相位。
- 器件选取两个能级来编码，不等于其余能级消失。
- 位置波函数、离散基系数与光子模式编码使用同一状态框架，但物理对象不同。

本篇不把量子力学解释争论、氢原子完整求解、散射理论全貌或量子场论设为量子计算的必修前置内容。相应方向可在掌握这里的算例后继续学习。
