# 第 56 轮：第 00 章修订记录

本轮将概览页改为“先抓流程、再算一个例子、最后看算法地图”的结构，不把术语表当作第一遍的必背清单。

- 增设分段阅读提示；定义振幅、模平方与归一化在本章的最小含义，并以 `|(1+i)/2|²=1/2` 核对。
- 把 `H|+⟩` 与 `H|−⟩` 展成两个 2×2 矩阵乘法，逐行展示相对相位导致哪一项振幅相消。加入经典无知与量子叠加的具体对照，并明说类比边界。
- 给 3 比特的 8 个标签与单次测量的一个结果，避免把“指数多振幅”误读为“指数多可直接读取的数”。
- 在算法表前解释其用途、$N$ 和查询模型；Grover 行限定无结构、唯一目标，另以一百万候选项展示查询量级而不许诺运行秒数。
- 用普通语言替换概览页未经介绍的 NP/BQP 包含式；拆开纠错“综合征、编码冗余、比较口径”的句子。
- 在一比特实验中从振幅算到概率及 1000 次的期望计数，移走未解释的 SPAM 缩写。
- 第 0 章自检由四题扩至六题，答案给计算步骤与端到端成本边界。

修订据 [第 55 轮审查](round55-ch00-audit.md)；数学公式仍需交叉复核和正式阅读版渲染。本报告不宣称整章或全书已无问题。
