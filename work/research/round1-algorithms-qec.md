## 1. 结论先行：这一部分最容易出现的结构性缺陷

一套面向初学者、又能支撑研究生继续读论文的教材，至少必须修正以下常见问题。

1. **把 oracle 当作免费魔法。** 必须先区分查询复杂度与端到端门复杂度。`一次 oracle 调用` 不等于 `一次物理门`，构造 oracle、加载数据、反计算垃圾位都可能主导总成本。
2. **把“量子并行”说成同时算出并读出所有答案。** 叠加态能让振幅经历相干演化，但测量不能列出全部函数值；算法的核心是把所需的全局性质编码为可观测的干涉结果。
3. **混淆全局相位和相对相位。** 单独基态上的相位 oracle 看似只加全局相位；对叠加态，不同基态获得不同相位，差异才可观测。相位回传必须逐式推导。
4. **把 QFT 的门数与经典 FFT 的输出任务直接比较。** QFT 作用在振幅上，测量只能给一个样本；它不是“用多项式时间输出全部傅里叶系数”。
5. **夸大 Deutsch–Jozsa。** 它对确定性经典算法有指数级查询优势，但对允许小错误的随机经典算法没有同样的指数优势。其价值主要是教学与概念史。
6. **漏掉算法的 promise。** Deutsch–Jozsa、Simon 等是承诺问题；若输入不满足承诺，结论不成立。
7. **把 Shor 写成“QFT 直接分解质因数”。** 真正结构是：经典随机选数与 `gcd` → 量子阶寻找 → 连分数 → 经典 `gcd`；模幂是量子电路的重成本，QFT 只是周期信息提取的一环。
8. **把 Grover 写成“搜索数据库只需平方根时间”。** 正确表述是黑盒/无结构搜索的查询复杂度为 `Θ(√(N/M))`；oracle 实现、数据访问、解的数目未知、验证和容错常数都必须计入。
9. **把 BQP 画成包住 NP。** 已知的是 `P ⊆ BPP ⊆ BQP ⊆ PP ⊆ PSPACE`；`NP` 与 `BQP` 的一般包含关系未知。Shor 不意味着量子机能多项式时间解决 NP 完全问题。
10. **用“指数加速”但不说明基线、输入模型和误差。** 每一次加速声明都要写明：问题、输入长度、访问模型、经典对手、成功概率、输出形式和资源指标。
11. **把 VQE/QAOA 描述成已证实的普适实用优势。** 它们是混合启发式算法，存在采样成本、优化陷阱、贫瘠高原、噪声、ansatz 偏差以及强经典基线；目前不能笼统声称一般量子优势。
12. **把三比特码称为完整量子纠错码。** 三比特重复码只能纠正单个 `X` 翻转，不能保护任意单量子比特误差；相位翻转甚至可能因编码而有三个发生位置。
13. **把纠错理解为“测量并知道量子态”。** 稳定子测量只提取错误综合征，不读取逻辑振幅 `α,β`；这不违反不可克隆定理。
14. **把阈值写成一个固定百分比。** 阈值依赖码族、噪声模型、操作电路、泄漏与相关误差、解码器和连接结构。“表面码阈值约 1%”只能作为特定模型的量级印象，不能当自然常数。
15. **从“低于阈值”直接跳到“可用容错计算”。** 还需要长时间稳定、快速重复综合征测量、实时解码、泄漏处理、逻辑门、状态制备、魔法态工厂和系统级资源调度。
16. **省略 Clifford 与非 Clifford 的成本鸿沟。** 稳定子操作本身不构成通用量子计算；容错 `T` 门通常依赖魔法态注入与蒸馏，并常主导时空开销。

## 3. Oracle、相位回传与反计算：必须讲透的共同语言

### 3.1 为什么经典函数不能直接写成 `|x⟩→|f(x)⟩`

若 `f` 不是一一映射，这个映射会把两个正交输入送到同一输出，不可能是酉变换。标准布尔 oracle 写成

\[
U_f|x\rangle|y\rangle=|x\rangle|y\oplus f(x)\rangle .
\]

对每个固定 `x`，第二寄存器只是一个可逆的异或置换，所以整体酉。教材必须画出三种层次：

- 数学抽象：给定可调用的 `U_f`；
- 逻辑实现：由可逆电路计算 `f`，复制结果，再把工作位反计算回 `|0…0⟩`；
- 物理成本：分解为本机门并进行容错实现。

“反计算”不能略过。若工作寄存器残留与 `x` 纠缠的垃圾态，后续干涉会被破坏。

### 3.2 相位回传逐步推导

令目标位为

\[
|-\rangle=\frac{|0\rangle-|1\rangle}{\sqrt 2}.
\]

则

\[
\begin{aligned}
U_f|x\rangle|-\rangle
&=\frac{|x\rangle|f(x)\rangle-|x\rangle|1\oplus f(x)\rangle}{\sqrt2}\\
&=(-1)^{f(x)}|x\rangle|-\rangle.
\end{aligned}
\]

对单个 `x`，前面的因子只是全局相位；对叠加态

\[
\sum_x\alpha_x|x\rangle|-\rangle
\mapsto
\sum_x(-1)^{f(x)}\alpha_x|x\rangle|-\rangle,
\]

各分量获得不同符号，因此变成可干涉的相对相位。这才是“回传”的信息作用。建议避免“相位从目标位倒流到控制位”这种拟物化说法；更准确的表述是：目标寄存器选在异或操作的特征态上，受控操作的特征值写入了控制分量的相位。

### 3.3 手算例题 A：二变量奇偶函数

给定 `f(x_1x_2)=x_1⊕x_2`，输入寄存器为均匀叠加，目标位为 `|-⟩`：

\[
|\psi_0\rangle=\frac12(|00\rangle+|01\rangle+|10\rangle+|11\rangle)|-\rangle.
\]

函数表为 `0,1,1,0`，所以调用 oracle 后

\[
|\psi_1\rangle=\frac12(|00\rangle-|01\rangle-|10\rangle+|11\rangle)|-\rangle.
\]

前两位恰为 `|−⟩|−⟩`。读者应亲自展开验证，并回答：若目标位改成 `|+⟩`，为什么完全没有相位信息？答案是 `X|+⟩=|+⟩`，特征值为 `+1`。

## 4. 四个查询算法：共同骨架、逐步推演与真正的加速

### 4.1 Deutsch–Jozsa

**问题。** 给定承诺函数 `f:{0,1}^n→{0,1}`，它要么恒定，要么恰有一半输入输出 0、一半输出 1。判断是哪一种。

相位 oracle 后输入寄存器为

\[
2^{-n/2}\sum_x(-1)^{f(x)}|x\rangle.
\]

再施加 `H^{⊗n}`，测到 `y` 的振幅为

\[
A(y)=2^{-n}\sum_x(-1)^{f(x)+x\cdot y}.
\]

特别地，

\[
A(0^n)=2^{-n}\sum_x(-1)^{f(x)}.
\]

恒定时其绝对值为 1；平衡时为 0。因此只需一次量子查询，测到 `0^n` 即恒定，否则平衡。

**手算例题 B（`n=2`）。**

- `f=0`：相位向量 `(1,1,1,1)/2`，末层 Hadamard 后为 `|00⟩`。
- `f=x_1`：相位向量 `(1,1,-1,-1)/2`，末层后为 `|10⟩`，所以判为平衡。
- 要求读者用上式计算四个 `A(y)`，不能只看电路图猜答案。

**边界。** 精确的确定性经典算法最坏需 `2^{n-1}+1` 次查询；但允许常数错误率的随机算法抽样常数次即可高概率区分。因此不能不加限定地说“对经典算法指数加速”。IBM 的教学材料也明确提醒这一点。

### 4.2 Bernstein–Vazirani

**问题。** oracle 保证 `f_s(x)=s·x mod 2`，求隐藏串 `s∈{0,1}^n`。

利用 Walsh 正交关系，末层振幅为

\[
A(y)=2^{-n}\sum_x(-1)^{(s\oplus y)\cdot x}=\delta_{y,s}.
\]

所以一次量子查询直接测得 `s`；标准经典查询模型中确定性求解需要 `n` 次查询（查询单位向量）。这是线性而非指数查询加速。

**手算例题 C（`s=101`）。** 列出八个 `x` 和 `f_s(x)=x_1⊕x_3`，写出相位符号，然后逐位因式分解：

\[
2^{-3/2}\sum_x(-1)^{s\cdot x}|x\rangle
=H^{\otimes3}|101\rangle.
\]

最后一层 Hadamard 得 `|101⟩`。教材要明确位序，避免把 `101` 画成端序反转。

### 4.3 Simon

**问题。** 给定 `f:{0,1}^n→{0,1}^n`，承诺存在非零 `s`，且

\[
f(x)=f(y)\iff y=x\oplus s.
\]

一次量子子程序的状态链为

\[
|0^n\rangle|0^n\rangle
\xrightarrow{H^{\otimes n},U_f}
2^{-n/2}\sum_x|x\rangle|f(x)\rangle.
\]

若测量第二寄存器得到某值，第一寄存器塌缩为

\[
\frac{|x_0\rangle+|x_0\oplus s\rangle}{\sqrt2}.
\]

再做 `H^{⊗n}`：

\[
\frac{1}{\sqrt{2^{n-1}}}
\sum_{y:y\cdot s=0}|y\rangle.
\]

每次测量给出一条模二线性方程 `y·s=0`。重复约 `O(n)` 次，收集 `n−1` 条线性无关方程，再用 GF(2) 高斯消元求 `s`。量子查询为 `O(n)`；经典随机查询需要约 `Θ(2^{n/2})` 才能通过生日碰撞找到一对同值输入。

**手算例题 D（`n=3,s=110`）。** 取一次测量后得到的配对为 `{001,111}`：

\[
\frac{|001\rangle+|111\rangle}{\sqrt2}
\xrightarrow{H^{\otimes3}}
\frac12(|000\rangle-|001\rangle+|110\rangle-|111\rangle),
\]

相位符号依赖所取 `x_0`，但支持集总是 `{000,001,110,111}`，均满足 `y_1⊕y_2=0`。若两次非零样本为 `001` 与 `110`，方程为 `s_3=0`、`s_1⊕s_2=0`；结合 `s≠000` 得 `s=110`。

**必须指出。** 测量第二寄存器不是算法必需步骤；将其忽略（取偏迹）会得到相同的第一寄存器测量分布。显式测量只是更适合初学者理解。

### 4.4 统一视角

建议在章末用一张图展示：

```text
相位 oracle / 函数 oracle
          │
          ├─ Hadamard = Z_2^n 上的 Fourier 变换
          │      ├─ DJ：检测零频分量
          │      ├─ BV：读出单个 Walsh 频率
          │      └─ Simon：采样与隐藏移位正交的频率
          │
          └─ 一般群上的 QFT
                 └─ Shor：采样周期/阶对应的频率
```

这比把四个算法写成互不相关的“电路菜谱”更能建立迁移能力。

## 5. QFT 与相位估计：必须避免“快算 FFT”的误解

### 5.1 定义与最小例子

对 `N=2^n`，

\[
F_N|x\rangle=\frac1{\sqrt N}\sum_{k=0}^{N-1}e^{2\pi i xk/N}|k\rangle.
\]

**手算例题 E。** 对 `N=4,x=1`：

\[
F_4|1\rangle=\frac12(|0\rangle+i|1\rangle-|2\rangle-i|3\rangle).
\]

让读者直接乘 `4×4` 矩阵，再用 Hadamard加受控相位门的分解验证。电路若不做末尾 SWAP，输出位序是反的；图、公式和代码必须采用同一端序约定。

精确 QFT 可用 `O(n^2)` 个 Hadamard与受控旋转门实现，近似 QFT 可删去极小角度旋转以降低门数。不要把它与经典算法“输出全部 `2^n` 个傅里叶系数”的任务直接比较：量子态中的振幅通常不能全部读出。

### 5.2 相位估计逐步链条

给定

\[
U|u\rangle=e^{2\pi i\phi}|u\rangle,
\]

`t` 个控制位经 Hadamard和受控 `U^{2^j}` 后成为

\[
2^{-t/2}\sum_{k=0}^{2^t-1}e^{2\pi i k\phi}|k\rangle|u\rangle.
\]

对第一寄存器做逆 QFT。若 `φ=m/2^t`，结果精确为 `|m⟩`；若不能用 `t` 位精确表示，则概率集中在最接近 `2^tφ` 的整数附近。教材应给出误差 `ε`、失败概率 `δ` 与控制位数/重复次数的关系，而非说“QPE 精确求本征值”。

**手算例题 F。** 若 `φ=5/8=0.101_2` 且 `t=3`，受控幂后的相位序列正是 `F_8|5⟩`，逆 QFT 输出 `|101⟩`。再设置 `φ=1/3`，让读者计算 `m=2,3` 附近的几何级数概率，理解有限精度峰而不是理想单柱。

**输入条件。** 若输入不是本征态，而是 `|ψ⟩=Σ_j c_j|u_j⟩`，QPE 测得第 `j` 个相位的概率为 `|c_j|^2`，并将系统投影到相应本征态。制备与目标本征态高重叠的初态本身可能很难。

## 6. Grover 与振幅放大

设有 `M` 个标记项，均匀态在“好/坏”二维子空间中写成

\[
|s\rangle=\sin\theta|G\rangle+\cos\theta|B\rangle,
\qquad \sin^2\theta=M/N.
\]

一次 Grover 迭代（标记相位翻转，再关于 `|s⟩` 反射）把角度增加 `2θ`：

\[
G^r|s\rangle=sin((2r+1)\theta)|G\rangle+
\cos((2r+1)\theta)|B\rangle.
\]

故选择 `r≈π/(4θ)−1/2`，查询复杂度为 `Θ(√(N/M))`。无结构黑盒模型下这一数量级是最优的。

**手算例题 G（四项精确命中）。** `N=4,M=1`，标记 `|10⟩`。初始振幅均为 `1/2`；oracle 后为 `(1/2,1/2,−1/2,1/2)`，均值为 `1/4`。扩散算子把每个振幅 `a` 变为 `2\bar a−a`，故三项变 0，标记项变 1。一次迭代后得到 `|10⟩`。

**必须补充的边界。**

- `M` 未知时不能盲目使用固定迭代次数，可用量子计数或随机化迭代策略。
- 迭代过多会“转过头”，成功率并非单调上升。
- oracle 不是数据库扫描的免费替身；若每次 oracle 本身成本为 `C_f`，总成本至少含 `Θ(C_f√(N/M))`。
- 对密码穷举通常只是指数的平方根，例如 `2^k→2^{k/2}`，不是多项式时间。

## 7. Shor：必须把量子和经典步骤接起来

### 7.1 因数分解如何归约到阶寻找

欲分解奇合数 `N`：

1. 随机取 `1<a<N`。
2. 计算 `g=gcd(a,N)`；若 `g>1` 已找到因子。
3. 用量子子程序求最小正整数 `r`，使 `a^r≡1 (mod N)`。
4. 若 `r` 为奇数，或 `a^{r/2}≡−1 (mod N)`，本轮失败，重选 `a`。
5. 否则 `a^r−1=(a^{r/2}−1)(a^{r/2}+1)`，计算
   `gcd(a^{r/2}−1,N)` 与 `gcd(a^{r/2}+1,N)` 得非平凡因子。

阶寻找用模乘算子

\[
U_a|y\rangle=|ay\bmod N\rangle
\]

的相位估计或等价周期寻找。测量结果给出接近 `k/r` 的有理数，再用连分数恢复候选分母 `r`，并以 `a^r mod N=1` 验证。

### 7.2 手算例题 H：`N=15,a=2`

模幂序列：

\[
2^0,2^1,2^2,2^3,2^4\pmod{15}=1,2,4,8,1,
\]

所以 `r=4`。若相位寄存器有 `t=8` 位，理想峰在

\[
y\in\{0,64,128,192\},\quad y/256\in\{0,1/4,1/2,3/4\}.
\]

例如测到 `64`，连分数直接给 `1/4`，候选阶为 4。然后

\[
2^{r/2}=4,\quad
\gcd(4-1,15)=3,\quad \gcd(4+1,15)=5.
\]

若测到 `128`，约分后只有 `1/2`，分母 2 不是阶，需要再次采样或合并信息。这一失败分支非常适合解释“有界错误量子算法”不是“一次必成”。

### 7.3 必须如实交代的成本与密码学含义

- 输入规模是 `L=⌈log_2N⌉`，Shor 的门数对 `L` 为多项式；不能把“多项式于位数”误写为“多项式于整数值”。
- QFT 不是主要全部成本；可逆模幂/模乘通常更重。
- 算法威胁 RSA 的因数分解基础，也通过离散对数版本威胁有限域和椭圆曲线体系；不是“破解所有加密”，对称密钥主要受 Grover 式平方根影响。
- 当前小整数演示常经过针对实例的编译，不能据此外推到 RSA-2048。IBM 教程明确说明完整 RSA-2048 需要数量级为数百万以上物理量子比特与极深容错电路；Gidney–Ekerå 的一组特定假设估计是约 2000 万噪声量子比特、约 8 小时，这只是模型化资源估计，不是设备承诺。

## 8. 复杂度类与“量子加速”应该怎样讲

### 8.1 最小定义

- `P`：经典确定性多项式时间可判定。
- `BPP`：经典随机多项式时间，错误概率至多 `1/3`。
- `BQP`：统一多项式规模量子电路族可判定，错误概率至多 `1/3`。常数 `1/3` 可通过重复与多数表决放大到指数小。
- `NP`：是实例有多项式长度经典证据，可由经典多项式时间验证。
- `QMA`：是实例有多项式量子态证据，可由量子多项式时间验证；它更像 `NP` 的量子证据版本，而不是 `BQP` 的同义词。
- `PP`：接受概率大于 `1/2` 即接受的概率多项式时间类，允许差距极小，因此通常不被视为实际可行计算。
- `PSPACE`：经典多项式空间。

已知包含关系画成

```text
P ⊆ BPP ⊆ BQP ⊆ PP ⊆ PSPACE
\____________/     
       与 NP 的一般关系未知

BQP ⊆ QMA，NP ⊆ QMA
```

图中不应画未经证明的严格包含，也不应把 `NP` 固定画在 `BQP` 外或内。Shor 只说明某些不知是否在 `BPP` 的问题进入 `BQP`；这不证明 `BPP≠BQP`，也不证明 `NP⊆BQP`。

### 8.2 六种不同的“快”

每个算法旁边放一张固定格式资源卡：

| 维度 | 必须回答的问题 |
|---|---|
| 查询复杂度 | 调用黑盒多少次？黑盒内部是否收费？ |
| 门复杂度/深度 | 分解到允许门集后多少门、多少串行层？ |
| 量子比特/空间 | 数据位、工作位、纠错位分别多少？ |
| 样本复杂度 | 为把统计误差降到 `ε` 要重复多少次？ |
| 端到端时间 | 态制备、经典优化、测量、解码和通信是否计入？ |
| 误差与成功率 | 是精确、常数成功率，还是加性/相对近似？ |

### 8.3 算法对照表

| 问题 | 经典基线 | 量子结果 | 正确限定 |
|---|---:|---:|---|
| Deutsch–Jozsa | 精确确定性 `2^{n-1}+1` 查询 | 1 查询 | 对随机有界错误经典算法无指数优势 |
| Bernstein–Vazirani | `n` 查询 | 1 查询 | 标准 oracle 模型；线性查询优势 |
| Simon | 随机经典 `Θ(2^{n/2})` 查询 | `O(n)` 查询 | 承诺问题；另有经典线性代数后处理 |
| 无结构搜索 | `Θ(N/M)` 查询 | `Θ(√(N/M))` 查询 | 二次且最优；oracle 成本另计 |
| 因数分解 | 最佳已知经典为亚指数 | 量子多项式于 `log N` | 需要大规模容错机；不是 NP 完全问题 |
| QFT | 完整经典向量 DFT 至少需读写指数数据 | `O(n^2)` 量子门（精确） | 不能输出全部振幅；通常是子程序 |
| Hamiltonian 模拟 | 随系统结构而异 | 对局域/稀疏/可块编码模型可高效 | 态制备与可观测量读取可能抹去优势 |
| VQE/QAOA | 强经典启发式众多 | 目前多为启发式 | 不得笼统声称普适优势 |

## 9. 量子模拟：从物理问题到可测答案的全链条

### 9.1 必须区分的两类模拟

- **模拟式量子模拟**：让可控量子系统的自然 Hamiltonian 模仿目标系统，通常专用、校准依赖强。
- **数字式量子模拟**：把目标演化 `e^{-iHt}` 编译成量子门；通用但有离散化、门综合和纠错开销。

完整工作流不应从 Trotter 公式突然开始，而应包含：物理模型选择 → 费米子/玻色子/自旋到量子比特编码 → 初态制备 → 时间演化或基态算法 → 可观测量测量 → 误差与资源分析。

### 9.2 Product formula 的最小推导

若 `H=A+B` 且 `[A,B]≠0`，一阶 Lie–Trotter 公式为

\[
e^{-i(A+B)t}\approx
\left(e^{-iAt/r}e^{-iBt/r}\right)^r,
\]

误差随步数 `r` 增大而下降；高阶 Suzuki 公式可获得更高阶误差，但门数和常数增大。

**手算例题 I：`H=X+Z`。** 精确演化为

\[
e^{-it(X+Z)}=
\cos(\sqrt2t)I-i\frac{\sin(\sqrt2t)}{\sqrt2}(X+Z).
\]

一阶一步近似为 `e^{-itX}e^{-itZ}`。由 BCH 展开及 `[X,Z]=-2iY`，指数中多出领先项 `it^2Y`，说明单步误差为 `O(t^2)`；分成 `r` 步，总误差量级降为 `O(t^2/r)`。这比只背公式更能解释“非对易性产生 Trotter 误差”。

### 9.3 更现代的方法与边界

教材应在入门层次点到为止地介绍：LCU/块编码、qubitization 与量子信号处理能在合适 oracle 模型下取得接近最优的 `t` 与精度依赖。Low–Chuang 的 qubitization 结果在其标准化 oracle 模型中给出 `O(t+log(1/ε))` 型查询复杂度。不能把这个式子脱离 Hamiltonian 归一化与访问模型单独宣传。

输出同样关键：若目的是输出完整波函数的全部 `2^n` 个振幅，测量会使任务重新变得指数；合理目标通常是能量、局域关联函数、散射率或少数可观测量。

## 10. 变分量子算法、VQE 与 QAOA

### 10.1 通用闭环

```text
参数 θ
  │
  ▼
制备 |ψ(θ)⟩ ──测量各项──► 估计代价 C(θ)
  ▲                              │
  └────────经典优化器更新─────────┘
```

每次代价估计不是一个确定数，而是有限 shots 的随机估计。总资源必须乘上：Hamiltonian 项数/分组数 × 每项 shots × 优化迭代数 × 噪声缓解倍率。

### 10.2 VQE：变分原理与一量子比特完整例题

VQE 以

\[
E(\theta)=\langle\psi(\theta)|H|\psi(\theta)\rangle
\]

为目标。对任意规范化态，精确期望满足 `E(θ)≥E_0`。这保证的是能量上界，不保证优化器找到全局最小，也不保证有限采样或带偏误差缓解后的数值仍严格保持上界。

**手算例题 J。** 令

\[
H=-Z-\frac12X,\qquad
|\psi(\theta)\rangle=R_y(\theta)|0\rangle.
\]

因 `⟨Z⟩=cosθ,⟨X⟩=sinθ`，

\[
E(\theta)=-\cos\theta-\tfrac12\sin\theta.
\]

令导数 `sinθ−(1/2)cosθ=0`，得 `tanθ=1/2`，最小值

\[
E_{\min}=-\sqrt{1+(1/2)^2}=-\frac{\sqrt5}{2}.
\]

随后让读者分别在 Z 基和经 Hadamard 后的 X 基估计两项，计算二项分布标准误差约随 `1/√S` 缩小。这一例同时连接变分原理与测量成本。

### 10.3 QAOA：一条边的可验证例题

MaxCut 的一条边 `(1,2)` 可写成

\[
C=\frac{1-Z_1Z_2}{2},\qquad B=X_1+X_2.
\]

`p=1` 的态为

\[
|\gamma,\beta\rangle=e^{-i\beta B}e^{-i\gamma C}|++\rangle.
\]

直接展开或在 Heisenberg 图景计算可得

\[
\langle C\rangle=\frac12\left[1+\sin(4\beta)\sin\gamma\right].
\]

取 `β=π/8,γ=π/2` 得 `⟨C⟩=1`，即此最小实例达到最优割。随后必须立刻说明：单边可精确求解不代表一般图在固定 `p` 下精确；一般性能依赖图实例、深度、参数训练、噪声与经典基线。

### 10.4 不可删掉的局限清单

1. **ansatz 偏差**：目标态可能不在可达态族中。
2. **可训练性**：过深、过随机或不合适的全局代价会出现梯度指数小的贫瘠高原；噪声也能诱发贫瘠高原。
3. **局部极小值/鞍点/窄谷**：经典优化器不保证全局最优。
4. **采样成本**：高精度能量估计可能需要大量电路执行，VQE 化学资源研究指出测量可成为实用优势的路障。
5. **噪声与误差缓解开销**：缓解不是免费纠错，往往以更多样本换偏差降低。
6. **经典可模拟性**：浅层、低纠缠或特殊结构电路可能被张量网络等经典方法高效模拟。
7. **基准选择偏差**：必须与最佳或至少强而透明的经典算法比较，而不是只比穷举。
8. **优化成本遗漏**：不能只报“最佳参数下电路深度”，必须计入寻找参数所需的全部评估。
9. **QAOA 名称边界**：`p` 增大提高表达能力不等于现实中单调提高结果，因为训练和噪声会恶化。
10. **尚无一般性保证**：对一般量子化学 VQE 或组合优化 QAOA，不应写“已证明能超过经典”。

## 11. 从三比特码到稳定子形式

### 11.1 三比特比特翻转码

编码不是复制未知态三份，而是

\[
\alpha|0\rangle+\beta|1\rangle
\mapsto
\alpha|000\rangle+\beta|111\rangle.
\]

后者是纠缠编码，不违反不可克隆定理。稳定子生成元可取

\[
S_1=Z_1Z_2,\qquad S_2=Z_2Z_3.
\]

**手算例题 K：综合征表。**

| 错误 | `S_1` | `S_2` | 修正 |
|---|---:|---:|---|
| `I` | `+1` | `+1` | 无 |
| `X_1` | `−1` | `+1` | `X_1` |
| `X_2` | `−1` | `−1` | `X_2` |
| `X_3` | `+1` | `−1` | `X_3` |

逻辑算符可取 `\bar X=X_1X_2X_3`、`\bar Z=Z_1`。任一 `Z_i` 与两个稳定子对易，不会被检测，并在码空间中等价于逻辑 `\bar Z`；因此它不是完整量子码。

### 11.2 为什么连续误差可以离散纠正

任意单量子比特算符可展开为

\[
E=aI+bX+cY+dZ.
\]

若一个码能纠正 Pauli 基 `{I,X,Y,Z}`，线性性使其能纠正任意单比特误差。稳定子综合征测量把不同可纠正 Pauli 分量投影到相应综合征分支，而不测量逻辑 `α,β`。不要说“噪声真的只发生离散的 X/Y/Z”；正确说法是纠错操作把连续误差的影响离散化为可处理的综合征分支。

一般 Knill–Laflamme 条件为：对码空间基 `|i_L⟩,|j_L⟩` 和待纠错误差集合 `{E_a}`，

\[
\langle i_L|E_a^\dagger E_b|j_L\rangle=C_{ab}\delta_{ij}.
\]

直观含义：环境/综合征可以区分错误，但不能获得逻辑态是哪一个的信息。

### 11.3 稳定子码的最小代数

`[[n,k,d]]` 稳定子码用 `n−k` 个独立、两两对易且不含 `−I` 的 Pauli 生成元定义；码空间是它们共同的 `+1` 本征空间，维数 `2^k`。错误综合征由错误与各生成元对易（`+1`）还是反对易（`−1`）给出。

距离 `d` 是保持码空间却执行非平凡逻辑作用的最小 Pauli 权重，也即正规化子 `N(S)\S` 中的最小权重。它能检测最多 `d−1` 个位置的错误，纠正最多 `⌊(d−1)/2⌋` 个任意位置错误。必须区分“检测”和“纠正”。

## 12. Shor、Steane、CSS 与 surface code

### 12.1 九量子比特 Shor 码

\[
|0_L\rangle=\left(\frac{|000\rangle+|111\rangle}{\sqrt2}\right)^{\otimes3},\quad
|1_L\rangle=\left(\frac{|000\rangle-|111\rangle}{\sqrt2}\right)^{\otimes3}.
\]

每组三比特重复结构处理位翻转；三组之间的相位重复结构处理相位翻转。`Y=iXZ` 同时含 X 与 Z 部分，因此也可纠正任意单位置 Pauli 错误。参数为 `[[9,1,3]]`。图示应分成“组内 Z 型校验”和“组间 X 型校验”两层，不要只放一张九线密集电路。

### 12.2 Steane `[[7,1,3]]` 码

它是 CSS 码，可由经典 `[7,4,3]` Hamming 码构造。可选三条 X 型生成元

\[
IIIXXXX,\quad IXXIIXX,\quad XIXIXIX,
\]

再把 X 全换成 Z 得三条 Z 型生成元。

**手算例题 L：由综合征定位 X 错误。** 依次测三条 Z 型生成元，把反对易记 1、对易记 0，则 `X_j` 的三位综合征就是校验矩阵第 `j` 列：

| 位置 `j` | 综合征 |
|---:|---:|
| 1 | 001 |
| 2 | 010 |
| 3 | 011 |
| 4 | 100 |
| 5 | 101 |
| 6 | 110 |
| 7 | 111 |

所以任何单个 X 错误都能定位。Z 错误由 X 型生成元同理定位，Y 错误在两类综合征都显现。该表是连接经典 Hamming 校验矩阵与量子 CSS 码最有效的入门例子。

### 12.3 Surface code 的几何直觉

教材至少应包含一张规范的二维格图，明确：

- 数据量子比特在哪里，综合征辅助量子比特在哪里；
- X 型与 Z 型稳定子分别作用在哪些邻居；
- 一条 Pauli 错误链通常只在端点产生综合征；
- 解码器根据综合征猜测一条修正链；
- 实际错误链与修正链合并若形成非平凡边界到边界路径/同调环，就成为逻辑错误；
- 码距 `d` 是最短非平凡逻辑链长度。

旋转平面 surface code 的一个常用布局每逻辑量子比特总计约 `2d^2−1` 个数据加测量量子比特，但布局、边界和测量方案不同会改变常数，不能把公式当作所有 surface code 的统一定义。

### 12.4 阈值定理应怎样准确表达

阈值定理的核心不是“纠错消灭噪声”，而是：在指定的局域噪声与容错操作假设下，若物理错误强度低于某个常数阈值，则可以用增长但可控的编码开销，把任意长理想计算模拟到任意小失败概率。

surface code 常见经验拟合形如

\[
p_L\approx A\left(\frac p{p_{\rm th}}\right)^{(d+1)/2},
\]

只应用作特定噪声与解码器下的近似示意。

**手算例题 M（明确标注“示意模型”）。** 取 `A=0.1,p=10^{-3},p_th=10^{-2}`：

- `d=3`：`p_L≈10^{-3}`；
- `d=5`：`p_L≈10^{-4}`；
- `d=7`：`p_L≈10^{-5}`。

该例只说明低于阈值后随距离指数压低的趋势，不能用于工程报价。若 `p>p_th`，增加 `d` 反而可能更差。阈值还会被相关噪声、泄漏、非均匀性、测量错误和解码延迟改变。

## 13. 容错、横向门与魔法态

### 13.1 纠错不等于容错

若一个带故障的 CNOT 把一个物理错误传播成同一码块内多个错误，单次错误就可能超出码能力。容错 gadget 的设计目标是限制错误传播，并让错误制备、综合征提取和修正本身也能失败而不导致灾难。需要讲到：验证辅助态、重复综合征、横向操作、格手术/编织、实时解码和 Pauli frame。

### 13.2 Eastin–Knill 的正确边界

横向门不在同一码块内部耦合物理子系统，因此天然限制错误扩散；但 Eastin–Knill 证明，能检测任意单物理子系统错误的量子码不可能拥有一个通用的横向逻辑门集。它不是说“容错通用计算不可能”，而是说必须结合其他机制，例如魔法态注入、码切换、规范固定或格手术。

### 13.3 为什么需要魔法态

Clifford 门、稳定子态制备和 Pauli 测量组成的稳定子计算可被经典多项式时间模拟，且不构成通用量子计算。加入非 Clifford 资源（常用 T 门）才可达到通用性。

典型路线是制备有噪魔法态

\[
|A\rangle=T|+\rangle=\frac{|0\rangle+e^{i\pi/4}|1\rangle}{\sqrt2},
\]

通过 Clifford 操作、测量与前馈把它“注入”为逻辑 T 门。魔法态蒸馏消耗许多低保真魔法态，产出较少的高保真态；只有输入噪声低于相应协议阈值时才能递归改善。教材应画出“原始注入 → 一级蒸馏 → 二级蒸馏 → 逻辑 T 消费”的工厂流程，并把产率、失败率和时空体积列为资源，而不是把 T 画成与逻辑 Clifford 同价的方框。

## 14. 建议制作的图表与美术规范

1. **相位回传四格图**：目标位为 `|0⟩,|1⟩,|+⟩,|−⟩` 时 X 的作用；用同一颜色标出特征值 `±1`。
2. **查询算法统一状态流图**：纵轴是算法步骤，横轴是 DJ/BV/Simon；每格只写状态的“信息形态”（值、相位、线性约束），避免四张重复电路。
3. **Grover 二维转角图**：`|B⟩,|G⟩` 两轴，标出 oracle 反射、扩散反射和总旋转 `2θ`；旁边配 N=4 振幅条形图。
4. **Shor 双轨流程图**：经典步骤用灰色、量子阶寻找用蓝色；失败重试箭头必须保留。
5. **复杂度地图**：只画已知包含，用虚线和问号表示 `NP` 与 `BQP` 未知关系；图注禁止暗示严格包含。
6. **量子模拟漏斗图**：物理模型 → 编码 → 态制备 → 演化 → 测量 → 经典后处理；每一层列一个潜在瓶颈。
7. **VQE/QAOA 闭环图**：用误差条显示代价估计是统计量，不是精确函数值。
8. **重复码综合征热图**：行是错误，列是稳定子，`+/-` 用色盲友好的蓝/橙与符号双编码。
9. **Shor→Steane→surface code 演进图**：分别突出“级联思想、CSS 代数、二维局域几何”，不要做成简单年代轴。
10. **surface code 错误链图**：分三幅显示真实错误、综合征端点、解码修正；第四幅显示合并后形成逻辑链的失败案例。
11. **容错资源栈**：物理量子比特 → 码块 → 逻辑 Clifford → 魔法态工厂 → 算法；面积近似表达资源比例，但注明示意非定量。

统一视觉约定：计算基态黑色，振幅/相位蓝色，错误橙红色，综合征紫色，经典控制灰色；任意颜色信息必须同时配形状或符号以照顾色觉差异。电路图始终标明高位/低位和读数端序。

## 15. 常见错误与建议改写

| 易误导写法 | 建议改写 |
|---|---|
| “量子机同时尝试所有答案。” | “电路让所有基态分量相干演化，再用干涉增强与所求性质相关的振幅；测量仍只给有限经典结果。” |
| “oracle 一步算完任意函数。” | “查询模型把 `U_f` 作为一次访问；端到端成本还要计算 `U_f` 的可逆实现。” |
| “相位回传把信息倒流到控制位。” | “目标寄存器处于受控操作的特征态，特征值成为控制分量的相对相位。” |
| “DJ 对经典计算指数加速。” | “相对精确确定性查询模型为指数差；相对有界错误随机查询没有该指数差。” |
| “QFT 比 FFT 指数快。” | “QFT 可用多项式门改变振幅，但不能读出全部傅里叶系数；只有嵌入合适算法才能形成端到端优势。” |
| “Grover 在任意数据库中 `√N` 时间找到元素。” | “在可相干调用的无结构 oracle 模型中需 `Θ(√N)` 次查询，实际总成本还含 oracle 与数据访问。” |
| “Shor 用量子并行试除所有因子。” | “Shor 把分解归约为阶寻找，用相位估计/QFT 提取周期，再由经典连分数和 gcd 恢复因子。” |
| “量子计算能高效解决 NP 问题。” | “是否 `NP⊆BQP` 未知；无结构 NP 搜索一般只有 Grover 的平方根改进。” |
| “VQE 给出精确基态。” | “VQE 在选定 ansatz 中最小化带统计误差的能量估计；存在表达、训练、采样和噪声误差。” |
| “QAOA 的层数越多现实效果一定越好。” | “理想最优值随可用表达空间不会变差，但训练和噪声可使实际结果随深度恶化。” |
| “三次复制保护一个量子态。” | “编码把一个逻辑态等距映射到三量子比特纠缠子空间，并未产生三份独立未知态。” |
| “测量错误位置不会破坏量子信息。” | “测量稳定子只获取综合征；它与逻辑信息对易，因此理想情况下不读取 `α,β`。” |
| “任意小噪声都能靠加量子比特修好。” | “只有在噪声与操作低于相应容错阈值且满足模型假设时，增大码距才会持续压低逻辑错误。” |
| “表面码阈值是 1%。” | “约 1% 是若干常见电路级噪声模型和解码器下的量级；具体阈值不是通用常数。” |
| “有了 surface code 就有通用量子计算。” | “还需逻辑门、实时解码、泄漏处理和非 Clifford 资源；T 门常通过昂贵的魔法态工厂提供。” |

## 16. 章末练习的梯度设计

### 基础层（能逐行算）

1. 对四个布尔函数计算 `U_f|x⟩|−⟩`，区分全局与相对相位。
2. 手算 `F_4|0⟩…F_4|3⟩` 并验证正交。
3. 完成 `s=011` 的 BV 八行符号表。
4. 用振幅均值完成 N=4 的 Grover 一次迭代。
5. 填写三比特重复码综合征表。

### 连接层（把概念接起来）

6. 证明 DJ 的 `A(0^n)` 判据，并解释随机经典抽样为何改变优势表述。
7. 对 Simon 的三条样本做 GF(2) 消元，并判断其中哪条线性相关。
8. 对 `N=21` 尝试不同 `a`，列出出现奇阶或 `a^{r/2}=−1` 的重试分支。
9. 推导二阶对称 Trotter `e^{-iAt/2r}e^{-iBt/r}e^{-iAt/2r}` 为什么消掉二阶领先误差。
10. 为两量子比特 Hamiltonian 的 Pauli 项设计测量分组并估算 shots。

### 研究入门层（要求论证边界）

11. 选择一条“量子优势”新闻声明，按六维资源卡逐项审核。
12. 比较 VQE 与相位估计求基态能量对态制备、深度和采样的不同要求。
13. 给出两个具有相同单门错误率但不同相关性的噪声模型，说明为何阈值不能只由平均错误率决定。
14. 查阅一个 surface-code 资源估算，分离数据逻辑量子比特、魔法态工厂和布线开销。
15. 解释 Eastin–Knill 与魔法态注入之间的逻辑关系，但不要误写成“定理强制唯一采用蒸馏”。

## 17. 后续逐页审稿清单

当教材正文到位后，应至少进行以下三轮，而不是只查错别字。

### 第二轮：数学与口径核验

- 每个 oracle 是否酉、输入输出寄存器尺寸是否一致？
- 每条状态链是否归一化？位序和 QFT 正负号是否前后一致？
- 所有复杂度是否写明变量是 `N` 还是 `n=log N`？
- 每个“指数/二次加速”是否指明经典基线与访问模型？
- 每个算法成功概率、promise 与失败重试是否写出？
- 稳定子是否两两对易，生成元数与 `[[n,k,d]]` 是否一致？
- syndrome 表的符号是否与电路测量约定一致？

### 第三轮：教学可达性核验

- 每个新抽象概念之前是否有 1–3 量子比特可手算例子？
- 公式之后是否解释每个量的物理/计算含义，而非只复述公式？
- 是否明确“为什么要做这一步”，而不只是列门序列？
- 是否把失败分支、有限精度和噪声结果也画出来？
- 练习是否从代数复现过渡到模型批判？

### 第四轮：图文与语言核验

- 电路、公式、表格是否使用同一端序？
- 颜色是否有符号冗余、灰度打印是否可读？
- 图注能否离开正文独立理解？
- 是否删去“神奇地”“瞬间”“同时得到所有答案”等夸张词？
- 是否把“我们不妨轻易看出”改成实际推导？
- 是否避免“赋能、抓手、范式跃迁、降维打击”等宣传或黑话？

只有三轮均无新增实质问题，才可认为本部分达到稳定稿，而不是把“没有发现”误写成“绝对没有问题”。
