## 3. 执行证据

环境：系统 Python 3.9.6。六脚本直接执行，全部 exit code 0；无网络、无硬件后端、无外部 Python 包依赖。

网络实验：种子69012，N=200000；解析总等待11.4285714286、额外存储7.8571428571；样本11.44125、7.87201；标准误0.02031090、0.01917044。六标准误只是固定模拟回归容限，不写作物理协议置信保证。

路由实验：种子69014，8个基向量与1个归一化复态，最大振幅误差0。断言比较完整复振幅而不是概率，另断言省略布局解释的非对称输入出现错误。

其余确定性输出见代码 README。章节推导与程序在参数、单位、分母和近似前提上逐项对应。
