# 第 62 轮交换审稿：算法组新增段落

只读范围：`handbook/05-noise-channels.md`、`06-algorithmic-primitives.md`、`07-algorithms.md`、`08-applications.md`、`13-quantum-information.md`、`16-advanced-algorithms-verification.md`、`18-channels-capacities-complexity.md` 中第 61 轮新增的段落。核对目标是公式、数值、定义条件与初学者是否可能把例子推广过界；未修改受审正文、共享答案或 `reader/`。

## 判定

本轮在指定新增段落中**未发现 P0、P1 或 P2 问题**。以下逐项列出独立复算，供主代理整合时核对；这不是对七章全部旧内容的无缺陷保证。

| 位置 | 复算与教学边界 | 结果 |
|---|---|---|
| 05 §3 两测量工具 | 甲的 $M_0=P_0,M_1=P_1$；乙的 $N_0=P_0,N_1=|0\rangle\langle1|$。逐项有 $M_k^\dagger M_k=N_k^\dagger N_k=P_k$；对 $|+\rangle$ 两结果各 $1/2$。甲丢记录后 $I/2$，乙丢记录后 $|0\rangle\langle0|$。效应相同、后态不同的结论成立。 | 正确；清楚区分 POVM 与测量工具。 |
| 06 §1 相干 oracle 反例 | $f(0)=0,f(1)=1$ 时，相干输入 $|+\rangle| -\rangle$ 经相位回踢使首位变 $| -\rangle$，再经 $H$ 必得 1。若先测首位而不保留相干叠加，其非选择态 $I/2$ 在任何只对分支施加 $\pm1$ 的相位后不变，再经 $H$ 仍为 $I/2$。 | 正确；论证限于此处“一次相干调用”比较，未宣称经典多次查询不可能完成任务。 |
| 07 §模拟二阶公式 | 每片 $e^{-iA\Delta/2}e^{-iB\Delta}e^{-iA\Delta/2}$，$\Delta=t/r$。总计初始 $3r$ 个指数因子，$r-1$ 处相邻 $A$ 半步可合并，故 $3r-(r-1)=2r+1$。标准固定 $t$ 条件下全局二阶误差为 $O(t^3/r^2)$。 | 正确；文中也明确该数不是原生门数。 |
| 08 §VQE 单次估计 | $H=0.7Z+0.2X$ 的谱为 $\pm\sqrt{0.53}$，基态 Bloch 向量为 $-(0.2,0,0.7)/\sqrt{0.53}$。两份独立基态上分别测 $Z,X$，都得 $-1$ 的概率是 $\frac{1+0.7/\sqrt{0.53}}2\frac{1+0.2/\sqrt{0.53}}2=0.6250990047\ldots$；当次项估计 $-0.9<-\sqrt{0.53}$。 | 数值和变分原理边界正确；明确使用两份独立制备。 |
| 13 §5 相对熵 | 对角态给 $D=\frac34\log_2(3/2)+\frac14\log_2(1/2)=0.1887218755\ldots=1-h_2(1/4)$ bit。同一复位信道把两态都送到 $|0\rangle\langle0|$，输出 $D=0$。 | 正确；未把单例冒充一般证明。 |
| 16 §7.5 能隙证书 | 能谱展开给 $E\ge f_0E_0+(1-f_0)(E_0+\Delta)$，故 $f_0\ge1-(E-E_0)/\Delta$。两级态 $\rho=.75|0\rangle\langle0|+.25|1\rangle\langle1|$、$H=.40|1\rangle\langle1|$ 的超额能量为 $.10$，恰有 $f_0=.75$，根保真度 $\sqrt{.75}$。 | 正确；假设非简并基态及已知能隙也已写明。 |
| 18 §4.2 相干信息 | 纯输入可用一维 $R$ 纯化；信道输出的 $RB$ 与 $B$ 同谱，故 $I_c=S(B)-S(RB)=0$。对所有输入取最大时至少为 0，而个别混态输入仍可给负值。 | 正确；没有混淆单次最大值与正则化容量。 |

独立一手对照：[Watrous 的量子信息教材](https://cs.uwaterloo.ca/~watrous/TQI/)用于测量工具与信道定义；[Childs 等人的二阶乘积公式误差研究](https://doi.org/10.1103/PhysRevX.11.011020)用于误差阶；[Devetak 的容量原始论文](https://arxiv.org/abs/quant-ph/0304127)用于相干信息与容量的任务边界。VQE、相对熵和能隙三处的数值是由文中给出的矩阵和概率式独立计算，不需要诉诸硬件性能声明。
