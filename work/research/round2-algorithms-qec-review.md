# 第二轮审读记录：算法、应用与量子纠错

## 1. 审读范围与方法

本轮只审读并修改以下文件：

- `handbook/06-algorithmic-primitives.md`
- `handbook/07-algorithms.md`
- `handbook/08-applications.md`
- `handbook/10-error-correction.md`

没有修改其他章节或 `sources/`。审查分为四层：

1. 逐式复算振幅、相位、综合征和示例数值；
2. 核查每条复杂度声明的输入变量、访问模型与输出形式；
3. 检查是否遗漏失败分支、有限精度、采样和工程成本；
4. 检查初学者是否能从最小实例走到一般公式，而非被迫跨越中间步骤。

## 2. 发现的主要问题

### 2.1 直接影响渲染或正确性的文本损坏

原稿存在多处 LaTeX 或控制字符损坏：

- 振幅放大公式中的 `\sin` 被写成普通 `sin`；
- Shor 的幂序列中 `\quad` 退化为 `quad`；
- `\gcd` 行中的 `\qquad` 退化为 `qquad`；
- 三比特编码公式中的 `\beta` 前含不可见退格控制字符。

这些问题会造成公式错误显示，并妨碍全文搜索，已全部消除。自动检查确认四个文件不再含换行、制表和回车之外的 ASCII 控制字符。

### 2.2 第 06 章：共同原语

发现的问题：

- 开头称“四个结构”，实际列出 oracle、相位回传、振幅放大、QFT、QPE 等多个结构；
- 相位回传只有结论，没有解释为什么固定基态上的全局相位会在叠加态中成为相对相位；
- Deutsch–Jozsa 没有区分精确确定性经典基线和有界错误随机经典基线；
- Bernstein–Vazirani 没有写出 Walsh 正交求和，也未说明经典需要 `n` 次标准查询；
- QFT 没有可手算最小例子和端序警告；
- QPE 缺少受控幂后的完整状态、不可精确表示相位时的概率含义、非本征态输入的结果；
- “受控 `U^{2^j}`”的获得成本没有展开。

已做改进：

- 新增查询、门/深度、端到端三类成本表；
- 逐行推导相位回传，并加入奇偶函数两比特例子；
- 增加 Deutsch–Jozsa 的一般振幅 `A(y)`、`n=2` 手算和随机经典边界；
- 增加 BV 的正交和、`s=101` 因式分解例子及线性查询优势口径；
- 修正 Grover 状态公式，并以振幅均值逐项算出 `N=4` 精确命中；
- 增加 `QFT_4|1>` 的四个复振幅与位序说明；
- 增加 QPE 的完整 Fourier 态、`phi=5/8` 三位例子、非本征态概率和受控幂成本；
- 补充分辨精确、有界错误、近似和启发式算法的口径。

### 2.3 第 07 章：代表算法

发现的问题：

- Simon 只给最终约束，没有展示函数寄存器测量后的余集态、Hadamard 相消条件或 GF(2) 手算；
- 经典查询只写“指数级”，未给 `Theta(2^{n/2})` 的生日碰撞模型；
- Grover 没有写出精确成功概率和未知解数失败模式；
- Shor 从“阶寻找”直接跳到结果，缺少模乘本征态、QPE 如何采样 `k/r`、连分数为什么可能约掉分母；
- 分解 15 的公式已损坏，且没有展示一次无效相位样本；
- 量子模拟只有 Trotter 公式，没有让读者看见非对易误差来自何处；
- HHL 的状态输出、条件数与全分量读出边界虽有提及，但缺少谱分解解释；
- 复杂度类列表没有把 `BQP subset PP subset PSPACE` 放在一条清晰关系中。

已做改进：

- 完整推导 Simon 的余集态、`1+(-1)^{s dot z}` 相消机制，加入 `s=110` 手算和线性消元；
- 给出 Simon 量子 `O(n)` 与经典随机 `Theta(2^{n/2})` 查询的承诺模型限定；
- 写出 Grover 的 `p_k=sin^2((2k+1)theta)`、未知 `M` 与过度旋转；
- 用模乘本征态推导 Shor 的相位 `k/r`，解释连分数、验证和重复采样；
- 在 `N=15,a=2,t=8` 中列出四个峰，并说明测得 `1/2` 只恢复分母 2，必须重试；
- 明确输入规模是 `L=ceil(log_2 N)`，模幂而非 QFT 通常是重成本；
- 加入 `H=X+Z` 的精确演化、BCH 对易子和 `O(t^2/r)` 一阶 Trotter 误差；
- 以谱分解解释 HHL 的倒特征值操作，并强化条件数、装载、读出限制；
- 增加 PP 定义和已知包含链，明确 NP 与 BQP 关系未知；
- 重做算法选择表，使每一项都附理论优势和必须追问的条件。

### 2.4 第 08 章：VQE、QAOA 与应用证据

发现的问题：

- VQE 只写 `E(theta)>=E0`，容易被误解为实际估计值永远不能低于基态；
- 没有说明有限 shots、带偏误差缓解可能破坏表观变分上界；
- 没有给出 Pauli 项如何分别测量及标准误差怎样随 shots 缩放；
- QAOA 只有定义，没有任何可独立复算的例子；
- QAOA 乘积的时间顺序没有显式展开；
- “提高采样概率”没有区分期望值、近似比和取得高质量单个解的概率；
- 量子优势的证据等级没有区分可运行性、正确性、算法优势和实用优势；
- 错误缓解与错误校正边界不够明确。

已做改进：

- 从本征态展开重新推导变分上界，并列出它不保证的五件事；
- 保留并细化一比特 `H=0.7Z+0.2X` 例子，写出 `R_y` 态、两个期望值和最小值；
- 加入 X/Z 两组测量与 Pauli 估计标准差上界 `1/sqrt(S)`；
- 显式展开 QAOA 的层顺序；
- 增加单边 MaxCut：`C=(1-Z1Z2)/2`，推导并数值核验 `p=1` 时 `⟨C⟩=[1+sin(4beta)sin(gamma)]/2`，给出达到最优的参数；
- 增加 QAOA 必报指标表和 VQE/QAOA 边界对照表；
- 扩充贫瘠高原、噪声诱导平坦、优化器噪声、经典可模拟性等失败模式；
- 增加四级证据框架，防止从“设备运行”跳到“实用优势”；
- 明确错误缓解改善统计量，不等于在计算过程中保护逻辑态。

### 2.5 第 10 章：错误校正与容错

发现的问题：

- 三比特编码公式有控制字符损坏；
- 没有给出逻辑 X/Z，因而未直接展示为何 Z 错误不可检测；
- “只需纠正 X/Y/Z”的解释太短，容易误写成物理噪声本来就是离散的；
- Knill–Laflamme 条件缺少逻辑基形式和退化码说明；
- Steane 码没有生成元或手算综合征，CSS 与 Hamming 码连接只停留在名称；
- Shor 码没有写出逻辑码字；
- surface code 缺少错误链、综合征端点、修正链和逻辑失败的几何关系；
- 阈值没有定量示意，也没有列出改变阈值的关键变量；
- 没有说明 Eastin–Knill 对横向通用门集的限制；
- 魔法态只列资源名词，没有给出 `|A>=T|+>`、注入/蒸馏逻辑和蒸馏输入阈值；
- 错误校正与错误缓解没有并排区分。

已做改进：

- 修复编码公式，增加三比特码完整综合征表、逻辑算符和 Z 错误解释；
- 写出 Shor 九量子比特码字，并解释连续误差如何在线性与综合征测量下离散化；
- 增加 Knill–Laflamme 的逻辑基表达与退化码边界；
- 精确定义 `[[n,k,d]]`、检测/纠正/擦除三种能力；
- 给出 Steane 六类生成元的构造方式和七个位置的三位综合征表；
- 用错误链流程图解释 surface-code 解码，并给出常见旋转补丁约 `2d^2-1` 的限定计数；
- 增加阈值依赖清单和明确标注为“示意”的 `d=3,5,7` 逻辑错误缩放表；
- 增加 fault-tolerant gadget、Eastin–Knill 的准确边界；
- 写出 T 矩阵与 `|A>`，说明注入、蒸馏、输入阈值及工厂资源；
- 新增 QEC 与 QEM 对照表；
- 将逻辑错误预算例子改为 `10^8` 层、总失败率 1% 对应每层约 `10^-10` 的保守量级，修正原稿过松的 `10^-8` 表述。

## 3. 独立复算结果

本轮用独立数值脚本复核以下易错点，均通过：

1. `QFT_4|1>=(1,i,-1,-i)/2`；
2. Simon 的 `(|001>+|111>)/sqrt(2)` 经三比特 Hadamard 后仅支持 `000,001,110,111`；
3. 单边 QAOA 在本文门号与符号约定下满足
   `⟨C⟩=[1+sin(4beta)sin(gamma)]/2`；
4. VQE 例子的数值最小值为 `-sqrt(0.53)`；
5. 所列 Steane 三条 Z 型生成元对 `X_1...X_7` 给出 `001...111` 七个不同综合征。

另以人工逐式检查复核：

- Grover `N=4,M=1` 一次迭代精确命中；
- Shor `N=15,a=2` 的阶为 4，`gcd(3,15)=3`、`gcd(5,15)=5`；
- `H=X+Z` 的 `[X,Z]=-2iY` 与一阶 BCH 附加项符号；
- 阈值示意式在 `A=0.1,p/p_th=0.1` 时依次给出 `10^-3,10^-4,10^-5`。

## 4. 残余风险与下一轮建议

本轮完成后，没有发现上述四章中仍未修正的已知公式错误，但还有以下不能仅靠 Markdown 源文消除的风险：

1. **最终渲染尚需视觉检查。** Mermaid、宽表、长公式在 PDF 与窄屏可能换行不佳；应在全书构建后逐页查看。
2. **全书端序与符号约定需跨章统一。** 本章已经提示 QFT 位序，但需要对照基础线路章和代码附录的高低位约定。
3. **复杂度表仍是入门层。** 若后续加入具体资源数，应说明逻辑门集、算术方案、目标错误率、物理噪声和解码器，不应把单篇估计写成通用数字。
4. **QAOA 小例只验证定义。** 它不能作为一般性能证据；若加入硬件实验，必须配同预算强经典基线。
5. **阈值缩放表是教学示意。** 出版排版时必须保留“示意模型”标识，不能截取为工程参数表。
6. **玻色码仅作拓展导引。** 若全书要深入 GKP/cat/binomial，需要另章解释连续变量、有限压缩与噪声偏置保持；本章不宜继续堆术语。
7. **参考链接与出版元数据。** DOI 均采用稳定入口，但最终出版前仍应统一参考文献格式，并检查网页课程是否改版。
8. **缺少可执行配套。** 手算例已经足够核验公式；若要提供代码，应单独测试端序、随机种子、模拟器噪声和依赖版本，不能从公式直接复制成未经测试的示例。

下一轮应先做全书渲染，再进行跨章节符号/端序检查与初学者试读，而不是继续增加高级算法名词。
